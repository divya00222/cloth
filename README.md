# AURA Studios - Premium Fashion E-Commerce Master Demo Template

Static HTML/CSS/Vanilla JavaScript project.

A high-end, production-quality **Frontend-Only** fashion and clothing e-commerce demo website crafted with clean, modern **HTML5, CSS3, and Vanilla JavaScript**.

Designed specifically as a reusable agency master template for presenting fashion stores to clients with high-conversion editorial presentation.

---

## 🚀 Running the Project

This is a pure **Static HTML/CSS/Vanilla JavaScript** project. No build tools, Node.js, Vite, React, or npm are required.

### OPTION 1:
Open `index.html` directly in a web browser.

### OPTION 2:
Upload the complete project folder to static hosting.

**Compatible hosting examples:**
- Hostinger
- cPanel hosting
- InfinityFree
- Netlify
- GitHub Pages

## 🔄 Master-Template Workflow

To adapt this template for a new fashion client, follow these steps:

1. **Duplicate the project** folder.
2. **Edit `assets/js/config.js`** to set brand name, currency, theme colors, phone, email, and social links.
3. **Edit `assets/js/products.js`** to replace or update product catalog items, categories, and prices.
4. **Edit `assets/js/campaigns.js`** to customize seasonal festival offers and banners.
5. **Replace product images** inside `assets/images/` or link to the client's image URLs.
6. **Replace logo/branding** text or image assets.
7. **Update contact information** in `config.js` (phone, WhatsApp, store address).
8. **Update campaign** preset to match the client's current season.
9. **Test all pages** in a browser to ensure complete consistency.
10. **Present the customized demo** to the client.
